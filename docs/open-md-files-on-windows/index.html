How to Open a .md File on Windows

A .md file is a Markdown document. Windows does not render Markdown by default, so the best way to open one depends on whether you want to read the raw text or see the formatted result. These five options cover quick edits, development work, and dedicated reading.

1. Notepad

Notepad is already on Windows. Right-click the file, choose Open with, and select Notepad. It opens the file as plain text, which makes it useful for a quick look at the source or a small edit.

Good for: quick text changes and checking the raw Markdown. Tradeoff: headings, lists, tables, and code blocks stay unformatted, so a longer document is harder to read.

2. Visual Studio Code preview

Open the file in Visual Studio Code and press Ctrl+Shift+V to open the Markdown preview. The editor shows the source beside or next to a rendered view, which is useful when you are writing and reading at the same time.

Good for: editing a README while checking the result. Tradeoff: VS Code is an editor first. The preview is a tab inside a larger development tool, and it is more than you need if you only want to read a file.

3. A web browser

You can drag a .md file into a browser window. Most browsers display the file as plain text rather than rendering the Markdown. Some extensions add a rendered view, but that is extra setup and another thing to keep updated.

Good for: reading the raw contents without installing anything. Tradeoff: no rendered headings, no folder tree, and no reading position to restore.

4. An online Markdown viewer

An online viewer lets you paste or upload a file and see the formatted result without installing an app. It is convenient for a one-off document or a quick preview on a machine you do not control.

Good for: a fast preview when you already have a network connection. Tradeoff: the document leaves your computer. Avoid online viewers for private repositories, internal notes, or anything confidential.

5. Glance

Glance is a Markdown viewer for Windows built for reading rather than editing. It opens a single file or a whole folder, renders GitHub-style Markdown, follows links, and keeps your place between launches. It also includes search, a contents rail, light and dark themes, live reload, and session restore.

Glance is source-available and free for noncommercial use. The current Windows build is unsigned, so Windows SmartScreen may warn on first launch. It is one option among the five here, and it is the most useful one when you want to read a repository of Markdown files instead of one file at a time.

Comparison

Method Renders Markdown Best for Tradeoff
Notepad No Quick text edits Raw text only
VS Code preview Yes Editing and previewing at once Large editor for a reading task
Web browser Usually no Reading raw text quickly No rendered view or folder tree
Online viewer Yes One-off previews Requires a network and sends the file out
Glance Yes Reading files and folders on Windows Windows only; unsigned build

Which method should you use?

Use Notepad or a browser when you only need the raw text. Use VS Code when you are already editing the document. Use an online viewer for a quick preview that does not contain private information. Use Glance when you want a dedicated Windows reader for README files, documentation folders, and long Markdown documents.
