Markdown Viewer for Windows

Glance is a desktop Markdown viewer for Windows 10 and Windows 11. It opens single files and whole folders, renders GitHub-style Markdown, and keeps your reading session between launches. It is source-available and free for noncommercial use.

What Glance does

  • Folder mode. Open a repository and browse every Markdown file from a tree. The root README.md opens automatically when it exists.
  • Live reload. Edit a file in your editor and Glance follows the change on disk while keeping your place in the document.
  • Search and contents. Jump by heading, find text in the current document, or search across the folder and the files you have open.
  • Themes. Follow the Windows theme or switch between light and dark by hand. Prose, code, tables, and diagrams change with it.
  • Session restore. Glance reopens the last document and the files you had open. Close any file from the sidebar when you are done with it.
  • Open with Glance. Double-click a Markdown file, use the Explorer context menu, or drop a file on the app icon. It opens in the existing window.

Glance is a reader, not an editor. Keep writing in your editor and use Glance for the formatted document, the folder tree, and a calmer reading window.

Frequently asked questions

Is Glance free?

Glance is free for noncommercial use. Commercial use requires a separate license. The source is available under the PolyForm Noncommercial License 1.0.0.

Does Glance work on macOS or Linux?

No. Glance is a Windows desktop app for Windows 10 and Windows 11.

Can Glance open a whole folder?

Yes. Folder mode shows the Markdown files in a tree and opens the root README.md automatically when it exists.

Does Glance render GitHub-style Markdown?

Glance renders GitHub-style Markdown, including tables, task lists, code blocks, links, and alerts. It also supports Mermaid diagrams and KaTeX math.

Is Glance source-available?
